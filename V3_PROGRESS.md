# BarberPro V3

Nesta etapa o projeto ganhou fluxo de aplicação real:

- Supabase SSR para navegador e servidor
- middleware de sessão
- tela de login/cadastro
- onboarding da primeira barbearia
- criação atômica de shop + owner
- API de serviços e jornada
- função SQL que calcula slots livres usando jornada, duração, buffer, bloqueios e reservas
- endpoint `/api/availability`
- página pública começou a ler barbearia e serviços do banco
- etapa de escolha do profissional filtra quem executa o serviço

Ainda faltam para o primeiro fluxo ponta a ponta:
- etapa visual data/horário
- criação pública segura do cliente
- confirmação do booking
- CRUDs visuais completos
- upload Storage
- convite de funcionários
- testes
